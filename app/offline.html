Bitcard offline key tool

For anyone who would rather not depend on a website at all. This page never uses the internet.

How this is different from the normal claim page. The quick page at bitcards.xyz/app.html rebuilds your full key inside a web page, so it trusts that the page was delivered honestly. This tool avoids that, but only when you run it from a saved copy on a device with no internet. Opened live from a website it is no safer than any website, so it will not accept your words until you save it and open the saved file. It contains no networking code, and it hands your key to a trusted wallet app (Sparrow or Electrum) to do the actual sending.
You are viewing this over the web, so word entry is turned off on purpose. To use it safely:
  1. Download this page: save bitcard-offline.html (or press Ctrl+S and choose "HTML only").
  2. Check its SHA-256 matches the value published at bitcards.xyz (for example, Get-FileHash on Windows, or shasum -a 256).
  3. Disconnect from the internet, then open the saved file. Word entry unlocks automatically.
  4. When you are finished, press Done to clear the screen, close the page, and only then reconnect.

One honest note: this page can tell that it was opened from a saved file, but it cannot tell whether your internet is actually switched off. What protects you is that this file contains no networking code at all, so it has no way to send anything anywhere.

Would rather not do all this? The normal claim page at bitcards.xyz/app.html does the same job in a couple of taps.

Open this card

Do this in a private place. Anyone who sees both sets of words, or the key below, can take the bitcoin.
How to move the bitcoin:
  1. Open a trusted wallet: Sparrow or Electrum (free, well known).
  2. Use its Sweep feature. Do NOT use "Import".
  3. Paste the private key above, choose your own wallet as the destination, and send.
  4. The wallet shows you the address, amount and fee before you confirm.
This card is a one-time key. After you sweep it, keep the card as a keepsake but do not reuse the key.
Is this tool genuine? (optional check)
This page does all its work on your device and has no way to reach the internet (its content policy is connect-src 'none' and it contains no networking code). It reproduces the same key as the open recovery method and the small Python recovery tool, so any of them can check the others. To be sure you have the real file, compare its full SHA-256 with the value published at bitcards.xyz, and best of all, get it from a source you trust and run it offline.
